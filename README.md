# Nanny Network — Connecting Families with Trusted Care

**Nanny Network** is a modern, responsive web platform designed to connect families with caring, background-checked, and CPR-certified childcare providers. Built with a warm, trustworthy aesthetic, the platform streamlines the process of finding, interviewing, booking, and managing nannies in real time.

---

## ✨ Key Features

- **Vetted Caregivers:** 100% background-checked, CPR-certified, and reference-verified nannies.
- **On-Demand & Recurring Care:** Flexible scheduling for full-time nannies, part-time help, or last-minute sitters.
- **Real-Time Care Updates:** Live daily activity logs, meal tracking, nap schedules, and milestone photo check-ins.
- **Trusted Community Ratings:** Verified reviews and testimonials from local parents and families.
- **Direct Chat & Seamless Pay:** Secure in-app messaging, interview scheduling, and automated payroll/hourly tracking.
- **Tailored Family Matching:** Smart matching technology based on specific family needs (multilingual skills, special needs care, tutoring, infant care).

## 🛠️ Tech Stack

- **HTML5:** Semantic page structure, accessible landmarks, embedded HTML5 background video, and mobile-first layout.
- **CSS3:** Custom CSS properties (`:root` variables), Flexbox & CSS Grid layouts, keyframe animations, backdrop blur filters, and responsive media queries.
- **JavaScript (ES6):** Scroll-triggered reveal animations, sticky navigation state, and interactive mobile drawer menu.
- **Font Awesome 6.5:** Crisp vector icons for store badges (Apple App Store, Google Play) and social media links.
- **Google Fonts:** *Comfortaa* (headings & brand logo) and *Poppins* / *Nunito* (body copy & UI controls).
